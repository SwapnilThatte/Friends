# Social Media Web App (MERN Stack)

A full-stack **social media web application** built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js), enabling real-time multi-user interactions, multimedia sharing, and intelligent moderation of content.  

---

## 🌟 Features

- **Real-time multi-user interaction** – Users can interact, comment, like, and follow in real time.  
- **Responsive frontend** – Built with **React.js**, ensuring smooth and interactive user experience on web and mobile.  
- **Rich multimedia support** – Upload and share images and videos seamlessly using **Google Firebase**.  
- **RESTful API backend** – Scalable and efficient APIs built with **Node.js** and **Express.js** for managing posts, comments, and users.  
- **AI-based content moderation** – Integrated **TensorFlow Lite** model to detect and prevent toxic comments and posts.  
- **Secure authentication** – JWT-based authentication and authorization for user security and role-based access.  

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Redux, React Router, CSS  
- **Backend:** Node.js, Express.js, RESTful APIs  
- **Database:** MongoDB (NoSQL)  
- **Storage:** Google Firebase (Images & Videos)  
- **AI/ML:** TensorFlow Lite (toxicity detection)  
- **Authentication:** JWT (JSON Web Tokens)
